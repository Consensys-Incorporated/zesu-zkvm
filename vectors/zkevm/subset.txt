# tests-zkevm blocks checked into ../ as zkevm.*.bin / zkevm.*.expected.hex.
#
# Every target's `make test` runs everything in ../, so these run on every zkVM in CI alongside
# the full mainnet/sepolia blocks. They are fed to the guest as raw SSZ, as ere does, and cover
# what the two real blocks do not: each precompile a zkVM accelerates, and blocks the guest must
# report as invalid instead of trapping.
#
# Regenerate (only when moving to a new fixture release) with fetch.py; see its docstring.
#
# Line format:   <glob>  [count]  [valid|invalid]  [pick=S]
#   glob     fnmatch pattern for fixture JSON paths, relative to blockchain_tests/for_amsterdam/
#   count    blocks to take from each matching file, spread evenly across its sorted test cases
#            (default 1; "all" takes every block)
#   filter   only blocks whose expected output has valid = true / false
#   pick=S   only test cases whose id contains S (choose a non-trivial input over an empty one)
